# 나의 첫 정적웹앱

HTML, CSS, JavaScript로 만든 수업용 시작 프로젝트입니다. 버튼을 누르면 클릭 횟수가 바뀝니다.

## 링크

- [REPO](https://github.com/junhyeok9679-arch/first-static-webapp)
- [실행하기](https://junhyeok9679-arch.github.io/first-static-webapp/)

## 실행

index.html을 브라우저에서 열거나 VS Code에서 Open with Live Server를 선택하세요.

## 파일

- index.html: 시작 페이지
- style.css: 화면 디자인
- app.js: 클릭 횟수 기능

## GitHub Pages

Settings → Pages → Deploy from a branch → main → /(root) → Save로 게시합니다.

## 실행 화면

실행 화면 캡처는 수업용 컴퓨터의 프로젝트 폴더에 저장합니다.
